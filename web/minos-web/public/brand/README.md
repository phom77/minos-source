# Brand assets

`dark-minos.png` and `light-minos.png` are the original Minos folded-M marks, preserved without pixel changes. The shell/authentication views use the dark mark on light surfaces and the light mark on dark surfaces, cropped through the existing SVG viewport to preserve proportions. The wordmark uses the system sans-serif stack.

`google-g.svg` retains Google's official G paths/colors for the sign-in action. Google's marks remain Google's property; follow the [Google identity branding guidelines](https://developers.google.com/identity/branding-guidelines). No remote logo request or Google script is required at runtime.

See [UI conventions](../../../../docs/ui.md) for palette and presentation rules.
